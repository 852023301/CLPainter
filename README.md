## 关于观测指标

### 进攻指标
#### 笔
1. 本级别趋势背驰一买+（次级别背驰）
2. 本级别二买+（RSI背驰、BOLL下轨支撑）
3. 本级别（类）三买+（次级别背驰）
4. 本级别中枢内部出现三笔类下跌盘整背驰（类二买）
