- 不同页面的绘图变更独立记录，恢复时合并；视窗保存不得删除绘图，旧页面的未修改图形不得复活其他页面已删除的图形。旧 v1 数据保留读取。

- 请求默认 30 秒超时，涵盖网络和响应解析；选股提供取消按钮，取消/超时释放忙态并忽略晚到结果。服务端已接收的请求不承诺被撤销，写操作超时需提示先核对列表。
- 写入失败时保留当前页可用性，但不能返回持久化成功；页面用可访问状态提示仅临时保存，明确刷新/关闭后可能丢失。

## 实现与兼容
- 保留原上下文键与旧 v1 数据读取。头部升级为 schema 2，作为视窗和合并快照；原有非空 v1 绘图/测量在首次迁移时留只读备份。绘图变更另存到各页面独占的记录键，使用唯一页面/图形 ID 和逻辑版本合并；视窗保存不写绘图日志，过期页面的未修改图形不会覆盖远端编辑或复活删除。相同图形的显式冲突按版本及稳定页面标识排序；没有后台清理其他页面的记录。
- 日志保存各图形的最新变更/删除标记，不做未经授权的跨页面压缩或浏览器数据清理；空间不足时保留本页状态并显示持久化警告。部署时模板与工作台片段必须一起更新，并刷新已有旧版标签页，不让旧脚本参与新版合并。

- 共享 JSON 请求边界默认 30 秒，覆盖网络及响应正文解析；即使传输层不响应 abort，前端也能释放等待，晚到数据不能再次提交。方案写请求超时提示先刷新核对，不承诺撤回已到达服务端的操作。
- 查询取消只作用于本次只读选股请求，返回可操作状态与可见焦点。每个指标面板有加载/失败状态、重试和取消；加载失败保留旧图并恢复实际指标选项，取消只退出该面板等待，不 abort 其他消费者共享的模块请求。超时或请求失败清除相应失败缓存，重试保留共享和身份检查。
