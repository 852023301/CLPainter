# MACD 背驰修复与验收口径

## 范围

本次属于行为修复，不是画线算法重构。只修改背驰比较器、MACD 副图附加分析字段与对应测试。
不修改笔、线段或中枢划分，不改状态数据库，不部署容器，不覆盖现有 curated / chart_payload。

## 判定规则

两个同向构件的区间必须对应同一份完整 K 线序列，比较范围为 `(start_idx, end_idx]`。
入口为 `macd_divergence(earlier, later, macd_data)`，前两个参数是笔或线段实例。
本次提交同时收录工作区已有的实例入参改造，不再使用独立的时间、索引、方向和终点价格参数。

确认背驰必须同时满足：

1. 后段终点创新高或创新低。
2. 前段同向柱面积大于零，后段同向柱面积严格小于前段。
3. 两段之间有反色柱，沿用原有门槛，本次没有删除。
4. 后段同向面积为零，或者后段 MACD 在段内出现过同向柱收缩。

转折的具体实现：将柱值乘以走势方向（上升为 +1，下降为 -1），
后段区间内至少有一次从正的方向化柱值向下收缩；只有反向柱增强不算同向收缩。
对于同向面积大于零的后段，全段持续增强、全段不变、只有一根柱且没有段内后继柱，均不能确认收缩；
回落后走平或重新增强均仍为已转折，不再要求末端最近一次变化为收缩。
不会读取 later.end_idx 之后的柱，不用未来 K 线补转折。

返回值新增 `macd_turned`，便于区分“面积缩小但未转折”和“已满足全部条件”。
没有同向柱时，同向面积为零，macd_turned 保持 False，但可通过独立的零面积分支满足背驰。
前段面积也为零、没有创新高/低、或者间隔没有反色柱时，不成立。
段内同向柱紧接着归零或翻成反向柱均算收缩；段外下一根不参与确认，也不参与面积统计。
“没有同向柱”使用未舍入的原始数值判断，不把显示舍入后的零或缺失数据当作零面积。
这不是笔本身已经最终确认、不再重画的保证，也不是中枢/趋势背驰分类器。

## 精度与 DIF

`calculate_macd_indicator()` 的每条 stats 新增 `macd_raw`、`dif_raw`。
现有 macd / dif / dea 显示字段、线条、标记、颜色和显示精度保持不变。
比较器优先取 raw 字段，避免显示精度改变面积、极值和间隔反色判断。

手工提供的 stats 只有 macd / dif 时，调用方必须传分析原值。
旧副图已经丢失的精度无法逆推；需要重新生成，不能声称旧缓存自动恢复了精度。
raw 字段部分缺失会直接报错，不混用舍入值和原值。

DIF 先按走势方向剔除反向值，再比较同向极值。
某段没有同向 DIF 时极值返回 None，`dif_lower=False`；没有 DIF 数据也不会影响柱面积判断。

## 输入验证

对实际分析的 MACD / DIF 列验证一维有限数值。
NaN、Infinity、None、非数字和嵌套数列抛出 ValueError，不伪装成有或没有背驰。
